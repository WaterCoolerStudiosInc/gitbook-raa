# Contribute to Open Source

Before going live with our open sourced code, we are building out the initial iteration of the Raa protocol using private repositories.

Please check this page again once Raa goes live as open source contributions will then be possible.

In the meantime, if you would like to be a part of the selective few who are building the foundation of Raa before going live, please fill out the following form for our team to review. We look forward to hearing from you!
